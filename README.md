A [make.fun](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6) entry for the **Snooze Button Roast** bounty: one line roasting an alarm clock that rings at 6 AM on a Saturday.

## Entry

> My alarm clock went off at 6 AM on a Saturday — the only thing in this house with a worse work-life balance than its unemployed owner.

## Run

Requires Node 22+ (TypeScript runs as-is):

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (one line, 134 characters, within the 1–200 character gate).
